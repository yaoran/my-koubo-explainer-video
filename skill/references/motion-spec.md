# 动效参数与原片对照

参数来自对参考片《陈天-AI视频》（1280×720，24fps，67 秒）的逐帧测量，实现于 `template/src/lib/anim.ts` 的 `DUR` 和 `template/src/components/SceneView.tsx`。想改手感时先看这里的依据。

## 画面坐标（1080p，参考片实测 ×1.5）

| 元素 | 位置 |
|---|---|
| 页眉细线 | y 42，x 64–1856 |
| 人物卡 | x 64，y 322，360×640，强调色底边向右下错位 14px |
| 信息区 | x 564 起，宽 1220；整块内容在 y 96–924 之间垂直居中 |
| 字幕条 | x 500–1856，y 940–1034 |
| 水印 | 右侧溢出 64px，y 786 起，字号 150 |
| 标题字号 | `xl` 97，`lg` 74，行高 1.12 |

## 节奏

| 动作 | 实测 | 模板取值 |
|---|---|---|
| 旧页左推出画 | 约 0.25 秒，先慢后快，整块滑出并在人物卡右侧被裁掉 | `pushOut: 0.25`，位移 −1500px |
| 新页滑入 | 旧页起步后约 0.17 秒开始，约 0.3 秒到位 | `pushInDelay: 0.17`，`pushIn: 0.32`，起始 +640px |
| 标题出现 | 页边界后约 0.27 秒，由虚到实约 0.2 秒 | `TITLE_DELAY: 0.27` |
| 正文第一个元素 | 页边界后约 0.7 秒 | `BODY_DELAY: 0.72` |
| 卡片进场 | 由虚到实 + 轻微上移，约 0.25 秒 | `enter: 0.26`，模糊 10px → 0 |
| 并列卡片间隔 | 0.15–0.3 秒 | `stagger: 0.17` |
| 列表逐行 | 每行间隔 0.085–0.13 秒 | 默认 0.09，或逐行写 `at` |
| 高亮变色 | 亮起约 0.17 秒，熄灭约 0.3 秒 | `color: 0.18`，`colorOff: 0.3` |
| 字幕切换 | 旧字幕淡出再淡入新字幕，各约 0.1 秒 | `caption: 0.12` |
| 全屏擦除 | 深色块 0.16 秒扫过，强调色块晚 0.06 秒跟上并盖满，停约 0.1 秒后向右撤走，全程约 0.47 秒；人物卡、页眉、字幕条始终在色块之上 | `wipeCover: 0.25`，`wipeClear: 0.47` |
| 水印 | 页面停留期间缓慢左移 | 整页 −24px |

参考片的做法是状态驱动：元素出现后就静止，只有说到新内容时才变化。不要加循环动画、弹跳或装饰性飞入。

## 和原片做对照

改了模板想确认没有跑偏时，用参考片的分镜渲染一版，和原片左右并排导出：

```bash
ffmpeg -y -i 原片.mp4 -i 复刻.mp4 -filter_complex \
  "[0:v]fps=30,scale=960:540[a];[1:v]scale=960:540[b];[a][b]hstack[v]" \
  -map "[v]" -map 1:a -c:v libx264 -crf 24 -pix_fmt yuv420p -shortest 对照.mp4
```

再按帧号抽几处换页和高亮的时刻逐帧比对。量时间用区域变化检测，比肉眼翻帧快：

```bash
# 只看右侧正文区，打印每次画面变化的时刻
ffmpeg -i 原片.mp4 -vf "crop=840:420:360:120,select='gt(scene,0.0012)',metadata=print:file=events.txt" -an -f null -
```

首次复刻的工程和对照视频保存在制作时选定的项目工作区，不随本 Skill 分发。
